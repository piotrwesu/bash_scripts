# bash_scripts
My bash scripts

- cdd.sh:

    Find and change directory

    `Usage: cdd dir_name`

- cdf.sh:

    Find file and change directory

    `Usage: cdf filename`

- dubel.sh 
   
   Find duplicated files
   
   `Usage: dubel files`

   Example: `dubel *.jpg`

- qcd.sh

    cd to bookmarks
    qcd [TAB]: to expand list
